Jetson: one-shot sudo

Normal agent shell and file tools run as the configured host user. This form runs one explicit command with sudo. The password is not saved in chat or sent to the model. Use HTTPS or a localhost SSH tunnel. Full host access is not a sandbox: only use this on a trusted host and application.

Enter the executable and arguments without a leading sudo. Shell syntax requires an explicit bash -lc 'command'. For short administrative commands only (30 seconds). A timeout does not guarantee cancellation.
